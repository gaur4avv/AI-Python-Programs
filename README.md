# AI Python Programs

A beginner-friendly collection of three Python programs demonstrating recursion, iteration, and object-oriented programming (OOP).

## Programs

| File | Concept | Description |
|---|---|---|
| `factorial.py` | Recursion | Calculates the factorial of a non-negative integer. |
| `fibonacci.py` | Loops | Generates the first *n* terms of the Fibonacci sequence. |
| `student.py` | Classes and objects | Stores and displays a student's name, roll number, and course. |

## Requirements

- Python 3.9 or later
- No third-party packages are required

## Run the programs

Clone the repository:

```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/AI-Python-Programs.git
cd AI-Python-Programs
```

Run any program:

```bash
python factorial.py
python fibonacci.py
python student.py
```

On some systems, use `python3` instead of `python`.

## Example runs

**Factorial**
```text
Enter a non-negative integer: 5
5! = 120
```

**Fibonacci**
```text
Enter the number of Fibonacci terms: 7
Fibonacci sequence: 0 1 1 2 3 5 8
```

**Student**
```text
Enter student name: Asha Sharma
Enter roll number: 24
Enter course: B.Tech CSE
--- Student Details ---
Name        : Asha Sharma
Roll Number : 24
Course      : B.Tech CSE
```

## Concepts demonstrated

- Defining and calling functions
- Recursive function calls and base cases
- `for` loops and sequence generation
- Input handling and basic validation
- Creating classes, objects, attributes, and methods
- Python's `if __name__ == "__main__":` entry-point pattern
